# Sa10kin Tap

## How do I install these formulae?

`brew install sa10kin/tap/<formula>`

Or `brew tap sa10kin/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sa10kin/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
